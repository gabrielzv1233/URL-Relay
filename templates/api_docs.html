URL Channel Relay

Publish HTTP or HTTPS URLs to a named channel. Every WebSocket receiver connected to that exact channel receives the URL.

GET

/api

This documentation page. It has no request fields.

POST

/api/post

Validate a URL and deliver it to every receiver on the selected channel.

Accepted fields

Field Required? Accepted in Description Example
url Required JSON, form, query, or X-URL header An absolute URL using http:// or https://. https://example.com/article
channel Optional JSON, form, query, or X-Channel header Exact channel name. Empty or omitted values default to none. desktop

Accepted request formats

  • application/json
  • application/x-www-form-urlencoded
  • Query parameters
  • X-URL and X-Channel headers

Example request

curl -X POST {{ request.host_url.rstrip('/') }}/api/post \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/article","channel":"desktop"}'

Successful response

{
  "ok": true,
  "url": "https://example.com/article",
  "channel": "desktop",
  "delivered": 1
}
WS GET upgrade

/api/socket?channel=<channel>

Open a WebSocket and listen for URLs published to one exact channel.

Accepted fields

Field Required? Accepted in Description Example
channel Optional Query string Exact channel to listen to. Empty or omitted values default to none. desktop

Example connection

const socket = new WebSocket(
  "ws://{{ request.host }}/api/socket?channel=desktop"
);

socket.onmessage = (event) => console.log(JSON.parse(event.data));

Received message

{
  "url": "https://example.com/article",
  "channel": "desktop"
}
Channels are exact, case-sensitive matches. This service does not currently require authentication.
